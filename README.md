# Buildzcrank

**AI-powered League of Legends companion** — champion guides, rune auto-import, item recommendations, draft assistant, and in-game overlays.

> Windows · Free · Auto-updates

---

## Download

**[→ Download latest version](https://github.com/Gombru22/Buildzcrank-releases/releases/latest)**

Run the installer (`Buildzcrank-Setup-x.x.x.exe`) and follow the steps. No admin rights required.

---

## Features

- **Champion Select** — AI draft recommendations, rune page auto-import when you lock in
- **In-game overlay** — item build suggestions and enemy summoner spell timers on top of the game
- **Champion guides** — skill order, runes and items for every champion
- **Explore** — browse champions, synergies and counters outside of games

---

## Requirements

- Windows 10 or later (64-bit)
- League of Legends installed and running

> The overlay requires League to run in **Borderless** or **Windowed** mode. It won't appear over Exclusive Fullscreen.

---

## Auto-updates

Buildzcrank updates itself automatically. When a new version is available it downloads in the background and installs the next time you close the app.
